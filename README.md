# Portfólio — João Victor Magalhães

Site estático responsivo para portfólio de Análise de Dados / Power BI.

## Como visualizar
Abra `index.html` no navegador.

## Antes de publicar
1. Troque `seuemail@exemplo.com` pelo seu e-mail real.
2. Atualize os links do LinkedIn e GitHub.
3. Substitua os projetos de exemplo por projetos que você realmente desenvolveu.
4. Atualize cursos e certificados com instituições e datas reais.
5. Revise a descrição das competências para refletir sua experiência.

Os indicadores apresentados nos dashboards são ilustrativos e não devem ser apresentados como resultados reais.

## Publicação gratuita
Você pode publicar a pasta usando GitHub Pages. Crie um repositório público, envie `index.html` e, nas configurações do repositório, habilite Pages para a branch principal.
